# Dokumentation

Die [README](../README.md) erklärt, was die Freifunk-Karte ist und wie du sie lokal ausprobierst. Hier steht der Rest, nach Aufgaben sortiert.

| Du möchtest … | Lies … |
|---|---|
| den **Parser** einrichten und betreiben | [Parser-Server einrichten](parser-server.md) |
| die **Karte** auf einen Webserver bringen | [Webserver einrichten](webserver.md) |
| eine **Einstellung nachschlagen** | [Konfiguration: Referenz](konfiguration.md) und [Befehle des Parsers](befehle.md) |
| sehen, **was die Läufe gefunden haben** | [Admin-Oberfläche](admin-oberflaeche.md) |
| **benachrichtigt werden**, wenn etwas schiefgeht | [Überwachung: healthchecks.io und InfluxDB](ueberwachung.md) |
| im Alltag **Probleme finden und beheben** | [Betrieb und Fehlersuche](betrieb.md) |
| den Reiter **Statistik** nutzen | [Statistik: Knotenzahl im Zeitverlauf](statistik.md) |
| wissen, **warum meine Community fehlt** | [Meine Community fehlt auf der Karte](community.md) |
| am Projekt **mitentwickeln** | [Entwicklung](entwicklung.md), [`PRD.md`](../PRD.md) (Design und Entscheidungen, Englisch), [Geschichte der Modernisierung](history.md) (Englisch) |
